| Parameter | Value |
|---|---|
| Benchmark | sysbench-tpcc |
| Scale factor | 10 |
| Run duration | 120s per run |
| Tenant counts (T) | 1, 4, 8, 16 |
| Client threads | 4 / endpoint |
| Neon version | `main` |
| Sysbench version | 1.0.20 |
| WarpDrive version (baseline) | `feat/op-counters` |

| Run date | 2026-07-17 |
| Cost model | GET/HEAD $0.0004/1k · PUT/COPY/POST/LIST/DELETE_OBJECTS $0.005/1k (AWS us-east-1, 2025) |
