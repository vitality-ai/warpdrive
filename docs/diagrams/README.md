# Diagrams

Each `.svg` here that has a matching `.excalidraw` file can be edited in
[Excalidraw](https://excalidraw.com): open the `.excalidraw` file, edit,
then save it and export the SVG over the old one.

The SVGs embed the Virgil font (Excalidraw, SIL Open Font License 1.1), so
they look the same on every machine.
